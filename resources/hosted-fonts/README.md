# Pinned print fonts

These unmodified Croscore and DejaVu font files come from the immutable MicroBook engine image `sha256:ca89556eff3b41ae67bfd2e1a3f1cf8ad10afe8c7f1d0d3085cd21d673e9c389` used by the self-hosted renderer. They are bundled for browser layout and embedded in prepared Cloudflare print documents so client operating-system fonts do not change print geometry.

Redistribution licenses are included in CROSCORE-LICENSE.txt and DEJAVU-LICENSE.txt. The build creates CSS aliases for the corresponding UI font names; it does not modify the font files.
