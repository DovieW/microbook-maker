# Security and deployment scope

MicroBook 2 is currently a personal/self-hosted application. Its Library is shared by everyone who can access the installation. It has no accounts or visitor isolation. Keep it on a trusted network or behind an authenticated access proxy; do not expose it as an anonymous public upload service.

Do not attach private books, PDFs, credentials or storage archives to public issues. Report vulnerabilities using GitHub's private vulnerability reporting feature if available; otherwise request a private contact route without publishing exploit details or private data.

Public hosting requires separate ownership checks, expiry, resource limits and process isolation. See [the hosting design](docs/PUBLIC_HOSTING.md).
